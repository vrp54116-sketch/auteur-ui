# Advisory Taste Principles

Subjective art-direction principles distilled from upstream design leaders.

- **advisory/personality-intent** (pbakaus/impeccable): Select a distinct visual personality before coding rather than settling for neutral SaaS aesthetics.
- **advisory/cohesive-palette-anchor** (nextlevelbuilder/ui-ux-pro-max-skill): Anchor interfaces with one primary chromatic hue and derive semantic states consistently.
- **advisory/editorial-restraint** (Leonxlnx/taste-skill): Exercise restraint by eliminating decorative visual elements that do not reinforce content hierarchy.
