# v0.1.0 Initial Public Release

Initial public release of `auteur-ui` — an installable skill for AI coding agents (Claude Code, opencode, Cursor, Codex, Antigravity) that compiles design taste at build time into deterministic code, executable contracts, and numerical lint rules.

### Features
- **Deterministic Taste Contract**: All aesthetic decisions locked into `.auteur-ui/contract.json` (<= 300 tokens).
- **5 Curated Looks**: `nocturne-editorial`, `swiss-utility`, `kinetic-pop`, `terminal-luxe`, and `paper-editorial`.
- **Zero Runtime Network**: Bundled offline assets including WAAPI motion primitives, Web Audio synth kits, OKLCH scales, and font pairings.
- **Headless Playwright Previewer**: Deterministic contact sheets rendered in under 4 seconds without cloud calls.
- **Strict Anti-Pattern Linter**: 100-point deterministic taste evaluation covering color contrast, type scale, spatial rhythm, and touch targets.
- **One-Command Installer**: Multi-agent adapter generator targeting Claude Code, OpenCode, Cursor, Codex, and Antigravity.
